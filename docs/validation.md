# Проверка проекта

Повторная проверка выполнена 23 ноября 2026 года.

| Проверка | Результат |
| --- | --- |
| API, Pytest | 16 тестов прошли на SQLite и повторно на отдельной PostgreSQL |
| Сроки, фильтры и ввод, Vitest | 16 тестов прошли |
| HTTP-клиент | 6 тестов прошли |
| Форма и действия на странице, React Testing Library | 8 тестов прошли |
| Обновление, резервные копии и откат, unittest | 13 тестов прошли |
| Ruff и форматирование Python | Проверены |
| TypeScript и production-сборка Vite | Проверены |
| Shell-скрипты и итоговая конфигурация Compose | Проверены синтаксически |

Всего 59 тестовых случаев. Повтор того же набора API на PostgreSQL не считается
дополнительными 16 тестами. Тесты скриптов используют подставные команды Docker
и curl; тесты интерфейса — подставные ответы API.

При проверке интерфейса добавляются задания с заданной датой, редактируются поля,
меняется статус и проверяются фильтры. Отдельно проверено, что при ошибке сохранения
текст остаётся в форме, неудачное выполнение не меняет статус, отмена удаления
не отправляет запрос, а удаление последнего задания предмета сбрасывает фильтр.

В проверках обновления воспроизводятся неудачная копия, ошибка миграции, отказ
новой версии, неудачный возврат прежней, блокировка второго запуска и неверная
версия в `/health`. Возврат уже работающей метки не изменяет историю версий.
Резервные копии создаются с правами 600.

В предыдущей локальной проверке также выполнены миграции Alembic вперёд, назад
и повторно вперёд, а дамп из шести заданий восстановлен в отдельную PostgreSQL.

Обновлённая сборка открыта в браузере с демонстрационной PostgreSQL. Проверены
список и карточка ближайшего срока, а также форма на ширине 390 px. Ширина
документа совпадает с шириной окна, горизонтального переполнения нет.

## Контейнеры и GitHub Actions

[Запуск № 3](https://github.com/zlvtv/studyflow/actions/runs/45241667371)
для коммита `f9a054c` завершился успешно: backend, frontend и containers.
Проверены настоящие PostgreSQL 16, FastAPI и Nginx в Docker Compose.
Сценарий подтвердил сохранность задач после пересоздания контейнеров,
восстановление копии в отдельную базу, ручной откат и автоматическое возвращение
прежних образов после отказа намеренно сломанного API. После отказа список задач
совпал с первоначальным. Отчёты Pytest, Vitest и журнал Compose сохранены
в артефактах запуска. Тестовое окружение после проверки удалено.

Локально также запущен отдельный проект `studyflow-course` на порту 8088.
Все три сервиса имеют состояние healthy; наружу опубликован только Nginx,
привязанный к 127.0.0.1. Добавлены шесть учебных примеров. Резервная копия
проверена через `restore-test.sh`: в изолированной базе восстановлено 6 задач.
Настройки и копии остаются локально и исключены из Git и исходного архива.

В текущей реализации используется GitHub Actions вместо GitLab из исходной темы.
Конфигурация GitLab сохранена как вариант переноса; выполненный GitLab pipeline
не заявляется. Постоянный публичный сервер не создавался: приложение работает
локально, а GitHub проверяет его во временном окружении.
